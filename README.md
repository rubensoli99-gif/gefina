# Gefina

Sistema para gestão de contas a receber

O gefina registra os clientes de uma organização e as faturas emitidas contra esses clientes, e aspresenta a visão consolidada da situação financeira que desses registros decorre. 

## Funcionalidades

- Cadastro e manutenção de clientes 
- Emissão e manutenção de faturas 
- listagens com busca, ordenação e paginação 
- Painel de indicadores consolidados 
- Acesso autenticado e administração de contas

## Fora do escopo

- Cadastro público de usuários 
- Recuperação de senha 
- Envio de arquivo imagem 
- Representação gráfica de séries temporais
